# Design tensions and rationale

The [current specification](../design.md) owns approved truth. These migrated records preserve rationale, source contracts, fixtures and iteration history. Their original Provisional/TBD wording is a timestamped record of that round, not a reopening of the now-approved Settings direction. Exact Android tokens and expressly pending behavior still require implementation evidence.

The old global Aquisição exploration is not approved. Consent now belongs to Privacidade e segurança; temporary acquisition files belong to Dados e armazenamento. Legacy Integrações taxonomy is superseded by public Providers. Folder Catalog remains an unapproved exploration. Atlas Manga and exceptional catalog/lifecycle values are synthetic scenarios, not product facts.

Read a relevant record alongside the current specification. New changes should update the specification and add scoped rationale here; do not rewrite old notes to pretend every detail was approved.
