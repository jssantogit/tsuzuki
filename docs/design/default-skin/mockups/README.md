# Default Skin mockup

Open [index.html](index.html) directly in a browser. It is the single current runnable entry for this design family. Assets remain relative under `assets/`; no build or package installation is required. The closing Sobre board is the initial visible composition. Earlier boards are preserved in the source and their existing local interactions; no new board selector or product controls were added during migration.

The HTML and all 31 source assets were copied unchanged. Module ordering is preserved because later boards reuse live earlier components. Do not remove earlier source blocks just because they are not on the initial board.

This is visual evidence, not Android implementation. Local controls demonstrate fixtures; device authentication, Android pickers, capture/sharing jobs, Provider execution and security verification are not executed here. Clipboard and directory APIs depend on browser permissions/support. No mockup action proves a real app operation.

- `assets/`: CSS/JS, local font files, real cover/brand assets and lookup snapshots needed by or useful for the preserved prototype.
- `history/personalizacao/`: previous HTML already present in the repository, preserved with relative links to the shared current font assets. It is historical evidence, not another current entry.

Global Aquisição and Folder Catalog code remains historical/unapproved; do not infer current requirements from it. [Current specification](../design.md) resolves status.

Local Segoe UI/Bahnschrift files came from the OpenDesign prototype. They are presentation inputs, not an Android font choice, an open-source license claim or permission for separate font distribution. Brand masters remain in [docs/brand](../../../brand/README.md); the local lockup is a prototype copy/transposition of the official asset. Covers and service marks are referential sample content, not Tsuzuki-owned artwork. Acquisition provenance and limitations are retained in the tension records.
